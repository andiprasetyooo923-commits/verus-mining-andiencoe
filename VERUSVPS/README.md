---

💻 Requirements

Recommended systems:

- Ubuntu 22.04 / 24.04 x86-64
- Debian x86-64
- Other compatible Linux x86-64 distributions

Check your VPS architecture:

uname -m

If the output is:

x86_64

your VPS is compatible with this binary.

«⚠️ This binary is compiled for Linux x86-64 and is not intended for ARM64 VPS.»

---

🚀 Installation

Clone the repository:

git clone https://github.com/andiprasetyooo923-commits/verus-mining-andiencoe.git

Enter the VERUSVPS directory:

cd verus-mining-andiencoe/VERUSVPS

Make the binary executable:

chmod +x verus

Run the miner:

./verus

Press Ctrl+C to stop mining.
