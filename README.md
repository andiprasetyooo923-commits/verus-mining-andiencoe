📱 ANDROID / TERMUX

The following versions are designed for Android phones using Termux:

- VERUSC
- VERUSJS
- VERUSPHP
- VERUSPHYTHON

🖥️ VPS / LINUX

VERUSVPS is designed for Linux VPS / servers using the x86-64 architecture.

Supported examples:

- Ubuntu 22.04 / 24.04 x86-64
- Debian x86-64
- Other compatible Linux x86-64 systems

Check your architecture:

uname -m

If the output is:

x86_64

the "VERUSVPS" binary is compatible.

«⚠️ VERUSVPS is compiled for Linux x86-64 and is not intended for ARM64 VPS.»

🚀 INSTALLATION & USAGE

📱 ANDROID PHONE — TERMUX

Clone the repository:

git clone https://github.com/andiprasetyooo923-commits/verus-mining-andiencoe.git

Enter the repository:

cd verus-mining-andiencoe

Choose the version you want:

cd VERUSPHP

Run the program:

php bot.php

«⚠️ Each version has different requirements and usage instructions. Please enter the corresponding folder and read its "README.md" before running the program.»

---

🖥️ VPS / LINUX

Clone the repository:

git clone https://github.com/andiprasetyooo923-commits/verus-mining-andiencoe.git

Enter the VPS folder:

cd verus-mining-andiencoe/VERUSVPS

Give execution permission:

chmod +x verus

Run:

./verus

Press Ctrl+C to stop mining.
